## 🌟 Featured Project — Nur Quran

<div align="center">

# نور قرآن 📖

### **Offline Quran App | القرآن الكريم دون نت**

</div>

**Nur Quran** is a simple, fast, and offline Quran application designed to make reading the Holy Quran accessible anytime and anywhere — without requiring an internet connection.

**نور قرآن** هو تطبيق بسيط وسريع لقراءة القرآن الكريم في أي وقت وأي مكان بدون الحاجة إلى الإنترنت.

### ✨ Highlights

- 📖 **Offline reading** — Read the Quran without internet
- 🔎 **Fast search** — Search by Surah name, number, or Arabic text
- ⚡ **Smooth performance** — Fast startup and navigation
- 🌙 **Dark mode** — Comfortable reading at night
- 📱 **Clean interface** — Simple and focused reading experience
- 🔖 **Easy navigation** — Quickly access Surahs and reading progress
- 🕌 **Lightweight** — Designed for a smooth experience

### 🆕 What's New

- Improved search for Surahs and verses
- Faster startup and smoother navigation
- Cleaner and more comfortable reading interface
- Improved dark mode contrast
- General performance, accuracy, and stability improvements

### 🧰 Built With

`React` · `Capacitor` · `Android`
